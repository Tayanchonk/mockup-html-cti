CTI Design System

Comprehensive design guidelines, principles, and components for the CTI Project Management System.

Design Principles

Professional

Clean, business-oriented design that reflects the serious nature of customs and logistics management.

Efficient

Streamlined interfaces that allow users to complete tasks quickly and with minimal cognitive load.

Accessible

Inclusive design that works for all users across different devices and accessibility needs.

Component Guidelines

Navigation

  • • Primary navigation uses CTI primary blue background
  • • Active states use white text with blue background
  • • Hover states use lighter blue background
  • • Mobile navigation uses hamburger menu
  • • Breadcrumbs for deep navigation hierarchy

Buttons

  • • Primary buttons use CTI primary blue
  • • Secondary buttons use gray or outline styles
  • • Accent buttons use green for positive actions
  • • Warning and error buttons use appropriate semantic colors
  • • Consistent padding: py-2 px-4 for standard size

Forms

  • • Labels use font-medium weight
  • • Inputs have border-gray-300 with focus states
  • • Focus states use CTI primary color
  • • Error states use red border and text
  • • Consistent spacing between form elements

Cards

  • • White background with shadow-md
  • • Rounded corners with rounded-lg
  • • Consistent padding of p-6
  • • Hover effects with shadow-lg transition
  • • Use icons to enhance visual hierarchy

Usage Guidelines

Do's

  • Use consistent spacing throughout the interface
  • Follow semantic color meanings (green for success, red for error)
  • Test designs on multiple screen sizes
  • Use proper typography hierarchy

Don'ts

  • Don't use colors outside the defined palette
  • Don't mix different design patterns inconsistently
  • Don't ignore accessibility requirements
  • Don't use too many font weights or sizes
